# Annotation status and policy

The current annotation policy is [POLICY.md](../annotations/POLICY.md).
The first pass now covers all 1,037 distinct ZuCo 1.0 sentences and 20,458 source
word occurrences, including SR, NR and TSR. The complete categorical labels are
in [word_labels.csv](../annotations/word_labels.csv). They were prepared by a
single agent reviewing the sentences, not generated by NRC at EEG-run time.

The table has both lexical and contextual labels. Named entities, negation,
idioms, irony, ambiguous senses, degree and damaged source text are documented.
Uncertain cases are retained in a separate CSV rather than forced into neutral.
Each sentence's sparse decisions are auditable in agent_decisions.tsv; the
compiler requires every source sentence to have an explicit review entry.

Primary EEG exports/probes use lexical/contextual agreement. Full labels and
mismatches remain available; this selection is not an assertion that other
sentiment processes do not exist. A known tokenization/encoding issue is
explicitly excluded when exact original-cache alignment cannot be verified.

Agent annotations are not human gold labels. Professors can inspect the complete
CSV, uncertainty sheet and polarity-difference sheet without labeling the whole
dataset themselves. An independent human/second-annotator validation sample is
a later quality check, not work being silently delegated to the user now.
